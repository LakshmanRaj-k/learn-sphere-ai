### models/

This folder will contain **data models** for LearnSphere AI, for example:

- `User` (student / lecturer)
- `Class` and `Enrollment`
- `Quiz` and `Question`
- `AnalyticsSnapshot`

You can implement these using:

- an ORM (e.g., Prisma, Sequelize, Mongoose), or
- plain SQL/driver code,
- or in‑memory/demo stores while prototyping.
